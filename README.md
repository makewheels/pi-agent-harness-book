# 从零读懂 Pi Agent Harness

一本写给**不读代码的人**的 [Pi](https://github.com/earendil-works/pi) 学习书。

Pi 是 earendil-works 开源的**极简、可自我扩展**的终端编码 agent。这本书用大白话 + 图解，把它从外到内讲一遍——不贴大段代码。

在线阅读：<https://makewheels.github.io/pi-agent-harness-book/>

## 本地构建

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows；macOS/Linux 用 source .venv/bin/activate
pip install mkdocs-material
mkdocs serve                  # http://127.0.0.1:8000
```
