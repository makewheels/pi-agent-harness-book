    从零读懂 Pi Agent Harness¶

    一本写给不读代码的人的 Pi 学习书

    这本书想干什么¶

    2025 年底，earendil-works 团队开源了一个叫 Pi 的终端编码 agent（仓库 earendil-works/pi，官网 pi.dev）。它看起来和 Claude Code、Codex 是一类东西——在终端里跟它聊天，它帮你写代码。

    但它又跟绝大多数 agent 完全反着来：

    Pi 故意只给你一台"发动机 + 四个轮子"，剩下的一切，让你自己装。

    它默认只给模型四个工具：读文件、写文件、改文件、跑命令。没有子代理、没有计划模式、没有 MCP、没有权限弹窗。那些花里胡哨的能力，全靠"扩展"来补——你可以自己写、从社区装，甚至直接对 Pi 说一句"给我造个 XX 扩展"，它就自己造出来。

    官方文档很全，但像参考手册。这本书要填的是中间那块空白：

    不贴大段代码，用大白话 + 生活化的例子，把 Pi 从外到内讲一遍。

    你不需要会写代码。你只需要好奇：一个号称"让你完全接管"的编码 agent，到底是什么样。

    为什么值得读¶

    把今天的编码 agent 按"出厂装了多少东西"分，是两个流派：

    • 整车出厂派——厂家替你把所有功能装好，拿来就用，但改不了。
    • 零件出厂派——核心小到你可以完全接管，一切自己组装。Pi 是这一派里最彻底的。

    读懂 Pi，你能拿到三样别的书给不了的东西：

    收获 为什么只有 Pi 教得了
    agent 的最小骨架 它把 agent 削到只剩"循环 + 4 个工具"，是最干净的解剖标本
    自我扩展的完整设计 extensions/skills/模板/包，四件套 + 热加载，全公开
    一种"敢不做"的设计观 六条"故意不内置"，条条带理由

    怎么读这本书¶

    全书四个部分，建议按顺序读：

    部分 内容 你会得到什么
    第一部分 初见（第1-3章） Pi 是什么、怎么跑起来、整体长什么样 能在自己电脑上跑起来，并建立全局印象
    第二部分 解剖器官（第4-7章） LLM 统一层、对话循环、工具执行、会话记忆 理解 agent 的核心工作原理
    第三部分 自我扩展之魂（第8-10章） extensions、skills/模板/主题、零件市场 理解 Pi 最有辨识度的能力
    第四部分 进阶与动手（第11-13章） 四种模式、终端渲染、组装你自己的 Pi 能动手改，并带走设计智慧

    每章的结构都一样：

    • 🎬 场景开头——先讲一个具体的故事，引出问题
    • 🧩 概念拆解——大白话 + 图解
    • 🧪 动手实验——编号实验，带难度星级（★ 看一就行，★★★ 要动手）
    • 🤔 思考题——章末几道开放题
    • 📝 小结——一句话带走本章

    版本说明¶

    Pi 迭代较快，部分能力（protocol/client/server 等）官方标注为实验性。本书以 2026 年 8 月中旬的仓库源码为准。如果你读的时候发现对不上，多半是它又变了——以你本机跑的为准。
